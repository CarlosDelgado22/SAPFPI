# 🎓 SAPFPI - Sistema de Gestión Académica

![HTML5](https://img.shields.io/badge/HTML5-E34F26?logo=html5&logoColor=white)
![CSS3](https://img.shields.io/badge/CSS3-1572B6?logo=css3&logoColor=white)
![JavaScript](https://img.shields.io/badge/JavaScript-F7DF1E?logo=javascript&logoColor=black)

Interfaz web para la administración y seguimiento de procesos formativos. Permite gestionar de manera centralizada instructores, competencias formativas, asignaciones y fichas tituladas mediante una interfaz de usuario organizada por pestañas y tablas interactivas.

---

## 🚀 Funcionalidades

* **Módulo de Instructores:** Consulta y visualización detallada del equipo instructor (identificación, contacto, tipo de vinculación y rol de liderazgo).
* **Módulo de Competencias:** Listado y clasificación de competencias según tipología y horas de duración.
* **Módulo de Asignaciones:** Interfaz para vincular instructores a competencias específicas.
* **Módulo de Fichas Tituladas:** Control de programas de formación, jornadas, ambientes asignados e instructor líder.
* **Navegación por Pestañas:** Interfaz dinámica sin recarga de página para alternar entre módulos.

---

## 🛠️ Tecnologías Empleadas

* **HTML5 Semántico:** Estructura de pestañas, tablas, controles de formulario y modales.
* **CSS3 Modular:** Estilos personalizados (`Inter`, diseño limpio, tarjetas, tablas y control de visualización activa/inactiva).
* **JavaScript Nativo (Vanilla JS):** Manipulación del DOM, eventos de cambio de pestaña y gestión de datos.
* **Iconografía:** Font Awesome 6.
